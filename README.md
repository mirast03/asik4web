# Assignment 4 — Forms and Validation

Five separate HTML pages demonstrate basic forms, HTML5 validation, Bootstrap styling, Bootstrap feedback, and a registration form.

## Pages

- `index.html` — Task 0: basic contact form
- `validation.html` — Task 1: HTML5 `required`, `type=email`, `maxlength`
- `bootstrap.html` — Task 2: Bootstrap form and responsive grid
- `bootstrap-validation.html` — Task 3: examples of `is-valid`, `is-invalid`, and feedback text
- `registration.html` — Task 4: registration form with HTML5 and Bootstrap feedback

Open `index.html` in a browser or use VS Code Live Server. The navbar links to all five pages. Bootstrap loads from jsDelivr, so an internet connection is needed for Bootstrap styles.

Task 3 displays fixed examples of valid and invalid classes. HTML5 still checks the inputs on submit. Task 4 uses Bootstrap's `was-validated` class, which shows HTML5 validity feedback without JavaScript. HTML5 alone cannot compare Password and Confirm Password, so matching is not checked.

## Publish with GitHub Pages

Push the files to GitHub. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Use the Pages URL shown there.
